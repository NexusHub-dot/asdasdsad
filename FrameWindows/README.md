# Internal Frame Windows component

Built into the Pulse Macro DLL by the parent CMake project. Build from the root.

The current algorithm, restore audit, width/endpoint definitions, developer comparison modes and limitations are documented in [FRAME_WINDOWS_AUDIT.md](../FRAME_WINDOWS_AUDIT.md).

The files under `tests/` contain standalone logic tests and an optional historical native smoke harness. The native harness is not compiled into the delivered package and was not run.
